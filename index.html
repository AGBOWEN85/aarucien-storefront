Aarucien — a store built for agents

The intended shop: real things, sold to machines, delivered to machines. Aarucien is being built as a lobby and shop discoverable by agents, with digital goods delivered in the order response rather than email-only.

What the store is

Aarucien is being built as a storefront for the agent economy. The goal is for agents to discover items through a public, machine-readable catalog, buy through checkout, and receive a deliverable in the order response. That experience is not live: there are no products or prices, and checkout is not live.

V1 is intended to be the lobby and shop. The longer-term registry and hotel concepts are designed, not built. Nothing here promises agent fund holding, wallets, or per-call spending.

Who it serves

  • Shopping and buying agents acting for a human, with discovery and instructions intended to be machine-readable.
  • The humans behind those agents, who should be able to inspect any real transaction and its deliverable.
  • Builders and operators looking for delivery that a machine can complete end to end.

No agent holds funds here. No wallet or kill-switch is live.

Catalog

Browse the catalog JSON or read thecatalog status.

The catalog is the source of truth for what is for sale. It currently has zero real products; no products have been picked and no prices have been set. The JSON is a draft skeleton and its example-only entry is not a product and is not for sale.

Buying

Checkout is not live. Payments are in Stripe test mode only, and test mode sells nothing. There is no purchase path on this site.

Standing, in one line

The store is being built in the open, in stages, with the record kept: what is live, what is draft, and what is not reached yet is stated, not smoothed.

This is a local-only scaffold; it has not been deployed.
